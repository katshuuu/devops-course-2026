# Мой пет-проект

Идея: Telegram-бот для учёта повседневных расходов. Пользователь пишет сумму и категорию (еда, транспорт, учёба), бот сохраняет запись и по команде `/stats` показывает траты за день, неделю и месяц.

Стек: Python, aiogram, SQLite, Docker

Цель: научиться собирать небольшой сервис с хранением данных, упаковывать его в Docker и позже подключать простой CI для проверки кода

Сроки реализации:
- неделя 1 — каркас бота, команды `/start` и `/add`;
- неделя 2 — категории, SQLite и `/stats`;
- неделя 3 — Dockerfile и запуск на своей машине.


## Хранение данных
SQLite: локальная файловая БД, не требует отдельного сервера,
но поддерживает SQL-запросы и агрегации — нужно для /stats
(суммы расходов по категориям и периодам). Файл базы будет
лежать внутри Docker-волюма, чтобы данные не терялись при
пересборке контейнера.
