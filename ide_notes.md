# Git в VS Code vs терминал

## Что удобно в VS Code

1. Панель Source Control сразу показывает изменённые файлы и позволяет открыть diff одним кликом — видно, что именно уйдёт в коммит.
2. Встроенный редактор конфликтов подсвечивает обе стороны merge и даёт выбрать нужный фрагмент без ручного разбора маркеров `<<<<<<<`.
3. GitLens показывает автора и дату для каждой строки (blame), поэтому проще понять, зачем строка появилась и кого спросить при ревью.

## Что удобнее делать в терминале

Сложные операции с историей — `rebase -i`, `cherry-pick`, `reflog` и точечный `reset` — в CLI прозрачнее: видно точные команды, их проще повторить на сервере по SSH и встроить в скрипт. IDE часто прячет эти шаги за кнопками, и ошибку сложнее откатить.
