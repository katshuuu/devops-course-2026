## Данные задания 3

Исходная ссылка из задания `http://cmj4.web.rice.edu/KMeans.zip` сейчас недоступна (редирект на forbidden). Используется эквивалентный классический набор **20news-18828** с той же структурой: 20 подкаталогов групп и ~1000 файлов в каждом.

```bash
cd pr12_kmeans
./download_20newsgroups.sh
```

После загрузки рядом с ноутбуком должен появиться каталог `KMeans/20_Newsgroups`. Ноутбук сначала читает его, затем при отсутствии пробует `fetch_20newsgroups`, и только потом — запасной учебный корпус.
